How it works

From chain sync to query, one pipeline

Yaci Store follows the chain from any Cardano node, turns every block into typed events, and fans them out to the stores you enable. Plugins filter what gets stored. The results land in your database and, optionally, in analytics-ready Parquet.

Features

Everything you need to build on Cardano data

Start with the stores you need and add more later. Every module is a standalone library and a Spring Boot starter, so the indexer grows with your application.

Modular by design

UTxO, blocks, transactions, assets, metadata, scripts, staking, governance and more. Turn each store on or off, or pull it in as its own Spring Boot starter.

Spring Boot starters
dependencies { + implementation 'com.bloxbean.cardano:yaci-store-utxo-spring-boot-starter:<version>' + implementation 'com.bloxbean.cardano:yaci-store-metadata-spring-boot-starter:<version>' + implementation 'com.bloxbean.cardano:yaci-store-assets-spring-boot-starter:<version>' }

Get started

Run it your way

Go from zero to indexing in minutes with Docker, or build a custom indexer with the same modules.

terminal
# Download the Docker distribution from GitHub Releases, then
# point it at a network in config/application.properties:
store.cardano.host=preprod-node.world.dev.cardano.org
store.cardano.port=30000
store.cardano.protocol-magic=1
 
$ ./yaci-store.sh start
$ ./yaci-store.sh logs:yaci-store
  • PostgreSQL included
  • Ledger-state profile
  • Grafana dashboards
